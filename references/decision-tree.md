# Academic CV Decision Tree

Use this document when a choice is ambiguous.

## A. Should a Research Profile be included?

Include a brief profile only when supplied evidence supports a specific, useful description of the applicant's current direction. One substantial project can suffice; item counts do not establish maturity. Omit generic profiles that add no information. A student may instead have a short Research Interests section without being described as an established researcher.

## B. Should Current Research Agenda be included?

Require all of the following:
- a real research puzzle/question;
- substantive or empirical scope;
- some conceptual/theoretical logic;
- a plausible design/evidence strategy.

If any are missing, do not invent them. Put the topic under Research Interests; use Research Papers only when an actual paper exists.

## C. Should a paper be listed under Selected Research Papers?

Include when at least one of these is true:
- it is central to the applicant's current research identity;
- it demonstrates a distinctive method or substantive expertise;
- it has conference/award relevance;
- it is substantially stronger than ordinary coursework.

Exclude or compress when it is a routine assignment, duplicates another listed project, or has little target relevance.

## D. Should an extracurricular item stay?

Ask whether it evidences at least one of:
- research ability;
- academic achievement;
- methodological competence;
- intellectual trajectory;
- relevant institutional/professional exposure;
- substantial academic leadership/service.

If none apply, it is a high-priority candidate for removal.

## E. Should a number be added?

Only when the number clarifies:
- selectivity;
- scale;
- scope;
- responsibility;
- outcome.

Do not add cosmetic counts simply to imitate corporate résumés.

## F. Is a two-page CV acceptable?

Yes, when the second page contains high-value academic evidence. Reduce low-value material before changing typography or margins.

## G. How should conflicting sources be handled?

1. Identify the exact fields that conflict.
2. Preserve both values in the audit notes.
3. Ask the user only if the conflict blocks a correct final artifact; otherwise flag it explicitly for resolution.
4. Never guess based on which file looks newer.

## H. How should research strands be handled?

- If they show genuine evolution: order them to make the trajectory visible.
- If they are parallel: distinguish primary vs secondary strands if useful.
- If they are unrelated: do not invent a unifying theory; reduce lower-relevance space.
