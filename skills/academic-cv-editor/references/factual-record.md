# Factual record and unresolved fields

Before substantial rewriting, maintain a compact field/source/value/status ledger. Use statuses confirmed, supplied, conflicting, missing, and planned. User statements are usable evidence; do not demand certificates for every fact. Preserve provenance when supplied records disagree. A newer filename alone is not an authoritative correction; an explicit user correction can resolve the field.

Continue editing unaffected content. Record both conflicting values in separate audit notes. For optional unresolved fields, omit from the draft and disclose the omission; for essential unresolved fields, mark the artifact as a draft and ask one focused question. Do not output contradictory alternatives or unresolved placeholders in a submission-ready CV. Never claim final readiness until essential conflicts are resolved.

Keep planned work in future-oriented wording. Separate work completed from work proposed in the same project. Do not convert an expected graduation date to an earned degree.

For every research claim, check source, actual contribution, evidence/method, completion status, and proposed wording. Missing details are not permission to invent sources, methods, findings, supervisors, publication venues, titles, or coauthors. If citation metadata is missing, provide a usable partial draft plus a precise missing-fields note, not a fabricated citation.

Return a concise change log and unresolved-items list outside the CV. Audit notes are not CV content.
