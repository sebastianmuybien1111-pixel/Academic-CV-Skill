# Privacy notice — Academic CV Editor

Academic CV Editor is a package of instructions, examples, and a LaTeX template. It does not contain a publisher-operated server, user account, or analytics component. Installing the plugin does not itself send your CV to the publisher.

If you provide CV content in ChatGPT or Codex, the host service processes it under its own terms and privacy controls. If you ask the assistant to use another connected service, that service may process the data under its own policies. The publisher does not control those services or their retention practices.

Do not publish your private CV data in the public GitHub repository. To ask a question or report an issue, use the repository's public Issues page without including sensitive personal information.

This notice describes the published skills-only package; update it before adding external servers, telemetry, or data collection.
